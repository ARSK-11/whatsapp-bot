🎉 3 ENDPOINT BARU UNTUK GRUP!

═══════════════════════════════════════════════════════════════════

📡 ENDPOINT BARU:

1. GET  /groups              → List semua grup
2. POST /send-group          → Kirim ke grup (by ID)
3. POST /send-group-name     → Kirim ke grup (by Name) ⭐

═══════════════════════════════════════════════════════════════════

🚀 CARA MENGGUNAKAN:

┌─────────────────────────────────────────────────────────────────┐
│ 1. LIST SEMUA GRUP                                              │
└─────────────────────────────────────────────────────────────────┘

curl http://localhost:3000/groups

Response:
{
  "success": true,
  "count": 3,
  "groups": [
    {
      "id": "123456789@g.us",
      "name": "Keluarga Besar",
      "participants": 15
    },
    ...
  ]
}


┌─────────────────────────────────────────────────────────────────┐
│ 2. KIRIM KE GRUP (BY ID)                                        │
└─────────────────────────────────────────────────────────────────┘

curl -X POST http://localhost:3000/send-group \
  -H "Content-Type: application/json" \
  -d '{
    "group_id": "123456789@g.us",
    "message": "Halo grup!"
  }'


┌─────────────────────────────────────────────────────────────────┐
│ 3. KIRIM KE GRUP (BY NAME) - PALING MUDAH! ⭐                  │
└─────────────────────────────────────────────────────────────────┘

curl -X POST http://localhost:3000/send-group-name \
  -H "Content-Type: application/json" \
  -d '{
    "group_name": "Keluarga",
    "message": "Halo keluarga!"
  }'

💡 Tidak perlu tahu Group ID!
💡 Nama tidak perlu exact match
💡 "Keluarga" akan match "Keluarga Besar", "Keluarga Kecil", dll

3️⃣  REMINDER MEETING:

5️⃣  BROADCAST KE MULTIPLE GRUP:

#!/bin/bash
GRUP_LIST=("Keluarga" "Tim" "Teman")
PESAN="📢 Pengumuman penting untuk semua!"

for grup in "${GRUP_LIST[@]}"; do
  curl -X POST http://localhost:3000/send-group-name \
    -H "Content-Type: application/json" \
    -d "{\"group_name\":\"$grup\",\"message\":\"$PESAN\"}"
  sleep 2
done

🔧 INTEGRASI CODE:

┌─────────────────────────────────────────────────────────────────┐
│ JAVASCRIPT                                                       │
└─────────────────────────────────────────────────────────────────┘

// List groups
const groups = await fetch('http://localhost:3000/groups')
  .then(res => res.json());

// Send to group
fetch('http://localhost:3000/send-group-name', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    group_name: 'Keluarga',
    message: 'Halo grup!'
  })
}).then(res => res.json()).then(console.log);


┌─────────────────────────────────────────────────────────────────┐
│ PYTHON                                                           │
└─────────────────────────────────────────────────────────────────┘

import requests

# List groups
groups = requests.get('http://localhost:3000/groups').json()

# Send to group
requests.post('http://localhost:3000/send-group-name', json={
    'group_name': 'Keluarga',
    'message': 'Halo dari Python!'
})


┌─────────────────────────────────────────────────────────────────┐
│ PHP                                                              │
└─────────────────────────────────────────────────────────────────┘

<?php
// List groups
$groups = file_get_contents('http://localhost:3000/groups');

// Send to group
$ch = curl_init('http://localhost:3000/send-group-name');
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    'group_name' => 'Keluarga',
    'message' => 'Halo dari PHP!'
]));
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
curl_exec($ch);
?>
