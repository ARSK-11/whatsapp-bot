🔟  LIST GRUP (CEK APAKAH Test_bot ADA)
───────────────────────────────────────────────────────────────────

curl http://localhost:3000/groups

Atau dengan format pretty:

curl -s http://localhost:3000/groups | jq .

Atau cari grup Test_bot saja:

curl -s http://localhost:3000/groups | jq '.groups[] | select(.name | contains("Test_bot"))'

💡 TIPS PENGGUNAAN:

1. Pastikan API server sudah running:
   npm run api

2. Pastikan bot sudah ready (scan QR jika perlu)

3. Copy salah satu command di atas

4. Paste di terminal dan tekan Enter

5. Cek grup Test_bot untuk melihat pesan

═══════════════════════════════════════════════════════════════════

🔧 TROUBLESHOOTING:

Error "Grup tidak ditemukan"?
→ Cek apakah nama grup benar dengan:
  curl http://localhost:3000/groups

Error "Bot belum siap"?
→ Tunggu sampai bot ready atau scan QR:
  curl http://localhost:3000/status

Error "Connection refused"?
→ Pastikan API server running:
  npm run api

📋 TEMPLATE UNTUK CUSTOM MESSAGE:
