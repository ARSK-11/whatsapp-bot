📋 FORMAT NOMOR YANG BENAR

Indonesia:
628123456789@c.us
│││        │
│││        └─ Nomor tanpa 0 di depan
││└────────── Kode negara (62)
│└─────────── Tanpa tanda +
└──────────── Format lengkap dengan @c.us

Contoh SALAH:
❌ +628123456789@c.us    → Ada tanda +
❌ 6208123456789@c.us    → Ada 0 setelah 62
❌ 628123456789          → Tidak ada @c.us
❌ 62 8123-456-789@c.us  → Ada spasi/tanda hubung

Contoh BENAR:
✅ 628123456789@c.us
✅ 6281234567890@c.us

⚠️ PENTING - ANTI SPAM

1. Delay minimal 2 detik antar pesan:
   await new Promise(r => setTimeout(r, 2000));

2. Jangan kirim terlalu banyak sekaligus
   Max ~20 pesan per menit

3. WhatsApp bisa ban akun jika spam

4. Test dulu ke nomor sendiri

5. Gunakan broadcast dengan bijak

📞 TROUBLESHOOTING

Q: Pesan tidak terkirim?
A: - Cek format nomor (harus ada @c.us)
   - Pastikan nomor terdaftar di WhatsApp
   - Cek koneksi internet
   - Lihat error di terminal

Q: Bot tidak respon perintah !send?
A: - Pastikan bot dalam status "ready"
   - Ketik !help untuk cek perintah tersedia
   - Restart bot jika perlu

Q: Error "Number not found"?
A: - Nomor tidak terdaftar di WhatsApp
   - Periksa format nomor
   - Coba nomor lain
