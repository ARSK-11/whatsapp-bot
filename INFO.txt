🚀 CARA MENJALANKAN

1. Install dependencies (sudah dilakukan):
   npm install

2. Jalankan bot:
   npm start
   
   atau:
   node index.js

3. Scan QR code yang muncul dengan WhatsApp

4. Tunggu pesan "✅ Bot WhatsApp siap digunakan!"

5. Test dengan mengirim: !ping

✨ FITUR UTAMA

📝 Perintah Dasar:
  • !ping        - Test bot
  • !help        - Daftar perintah
  • !info        - Info bot
  • !time        - Waktu sekarang

💬 Perintah Chat:
  • !quote       - Quote motivasi
  • !say <teks>  - Bot ulangi teks
  
🎲 Hiburan:
  • !dice        - Lempar dadu
  • !flip        - Lempar koin
  • !joke        - Cerita lucu

🧮 Utilitas:
  • !calc <expr> - Kalkulator

🎨 Media:
  • !sticker     - Buat sticker (reply ke gambar)

👥 Grup:
  • !group       - Info grup
  • !tagall      - Tag semua (admin only)

💡 TIPS

1. Session tersimpan di folder .wwebjs_auth/
2. Tidak perlu scan QR setiap restart
3. Bot bekerja di personal chat & grup
4. Semua perintah pakai prefix !
5. Case insensitive (PING = ping)

⚠️ TROUBLESHOOTING

QR tidak muncul:
→ npm install
→ Cek koneksi internet
→ Restart bot

Bot tidak respon:
→ Tunggu status "ready"
→ Pastikan pakai prefix !
→ Cek error di terminal

Session error:
→ rm -rf .wwebjs_auth/
→ npm start
→ Scan QR lagi
